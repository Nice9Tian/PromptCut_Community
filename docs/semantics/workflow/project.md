# 项目：开始与交付

展开 `../user-workflow.md` 主线的第 0 步「开始」和第 5 步「交付」，以及项目级的设置。从属于 `user-workflow.md`，与它冲突时以它为准。

## 开始

- 开始页：新建空项目；打开本地草稿；打开 `.proc`（项目）或 `.procp`（项目 + 素材打包）；加入别人的项目。
- 项目只有一种新建入口。要和别人一起做，在项目设置里勾「多用户协作」；加入别人的项目在开始页。见下文「多用户协作」。
- 开始页显示拓展功能的状态并可就地安装。拓展提供的能力见 `materials.md`。
- 草稿自动保存在本机，开始页可列出、打开、删除。
- 开始页有「存储」〔裁：入口位置，2026-09-29 PC 主会话按用户定的「给清理缓存入口、导出产物有列表大小与删除」落实〕：显示本机的预渲染缓存与导出产物各占多少，以及缓存上限（可改）；「清理缓存」；导出产物按每次导出列出（所属项目、时间、大小），可打开所在目录、删除，也可只删中间文件、留下成片与透明层。标题栏菜单另有「存储…」直达这里。在线浏览器没有这一块。
- 打开旧项目时给一次性迁移提示（素材分类变化、已停用的 Python 卡）。
- 在线浏览器的开始页有“新建云端项目”和“加入别人的项目”；未登录时一边是“需要登录网站账号”，一边是“以游客身份进入”（2026-10-23 用户定）。点了游客就直接进来，系统随机给一个编号和头像，显示成「游客-7F3A」这样；进来之前先把游客能干到哪一步说清楚（1 个项目、3 条视频、每条源文件 100 MB 以内、3 天清理、别人的项目只能看）。身份在这台浏览器里记住，下次来还是同一个人，旁边有“换一个”；他自己建的那个项目也记在这台浏览器里，开始页直接列出来（游客没有“我创建的”那张表，那是向网站账号要的）。想长期保存就去注册账号，登录之后游客身份作废。新建前登录网站账号或以游客身份进入，项目一律放云端并勾上“多用户协作”，创建者为该账号或该游客。本地草稿列表、打开 `.proc` 只在桌面版；暂时离线的未提交改动仍需保留（见 `../product/platforms.md`“在线浏览器”）。
- 在线浏览器进了云端项目，地址栏就是这个项目的直达地址，刷新后还在这个项目里；把它收藏起来，下次打开直接进项目（没登录先登录）。点「首页」回开始页，地址回到 `/editor`（2026-10-23 用户定）。

## 多用户协作

- 项目设置里有一个勾选「多用户协作」，新建时和之后任何时候都可以勾上或取消。
- 勾上并保存：本机项目交给本地文档服务托管，同时向云端托管服务登记（离线时稍后自动补）。等待完成后显示邀请链接与二维码（里面是邀请码），并提醒「你的电脑关机后其他人打不开，可在设置里搬到云端」。
  - 本机不能从公网直连时，另提示「局域网外的成员将经中继加入，会受限速」；离线时提示「当前离线，局域网外成员暂时无法加入」。项目照建，不锁任何选项。
- 勾上时的默认：放本机、自由进入、创建者用户名取设备名、密码自动生成并存在本机。这些都可以在项目设置里改，改法沿用创建者的三项特权。
- 取消并保存：等所有内容拉回本机，之后云端托管服务注销登记，其他成员不再能进。项目已在云端的，取消前先把内容全部拉回本机。
- 项目设置里另有「搬到云端」「搬回本机」。本地项目搬到云端搬上去还是同一个项目，历史序号接着往上数，操作历史也连着（2026-10-14 用户定）。0.7.18 不再支持旧版本客户端：旧版本点「搬到云端」时提示「当前软件版本已过期，无法搬到云端」。搬不上去时的提示只要一句：「这个云端只接受网站账号」。原来限定进入的房间搬上去后，知道链接、登录了就能进，原来被踢的人也能进；搬完提示创建者「原来的禁入名单没有带过去」。搬失败后「再点一次」接着用云端已经建好的项目；搬完自动在本机存一次。不想接着搬的，在项目设置里点「放弃这次搬迁」，确认后删掉那个没搬完的云端项目，本机这一份不受影响；这个按钮只在有这样一个云端项目时出现。〔裁：H04，用户 2026-10-22 定「开一个分支做」；报告 `docs/reports/AGENT-claude-abandon-move.md`〕
- 保存 `.proc`、`.procp` 和草稿保留非秘密的房间关联；各设备持久保存自己的恢复凭证，普通项目文件不含认证秘密。原设备凭有效凭证重开后自动恢复原身份；凭证丢失、失效或新设备打开时明确要求认证，不仅凭文件内的用户名或角色授权。〔裁：用户授权 `collaboration-reopen-recovery-plan.md` 第 10 节〕
- 原主机在原设备重开后恢复原房间并重新登记上线，地址变化及暂时网络失败自动处理；成员先打开时保留身份等待，主机上线后自动重试。创建者第二设备只恢复创建者连接；云端项目仍存在时恢复云端身份，不自动搬回本机。只有可信云端文档服务确认准确原项目已不存在，才走下文“过期云端项目转本地”。
- 正常重入以服务端最新内容和连续历史序号为准，不把文件快照自动覆盖共享项目。取消或删除是持久的显式操作，旧文件与后台重试不得撤销；恢复数据缺失或损坏须保留本地内容并明确提示。〔裁：同上〕
- 加入别人的项目在开始页，桌面版和在线浏览器一样。本地项目表单仍为项目名、项目密码、自己的用户名；限定进入填名单里的用户名和密码。云端项目要登录网站账号，由服务器核对。游客也能凭链接加入云端项目（只在在线浏览器里），但进去只能看：改不了内容、存不了、也不能给云端 Agent 发消息，界面上说明「你在这个项目里只能查看」（2026-10-23 用户定）。桌面版在编辑器里输一次账号名和密码，同设备以后用可撤销的恢复凭证重开，设备不保存密码；在线浏览器和官网共用登录，官网登录过就不用再输，下次还在不在看登录时有没有勾「记住登录状态」（2026-10-08 用户定，原写「网站已登录仍需在编辑器输入一次」只对桌面版成立）。被账号名单挡住的人看到「你不在这个项目的成员名单中」和「发送申请」按钮，发出后显示「已发送，等创建者通过」。申请列表在成员浮层里，有新申请时成员按钮上出数字角标，每条有「通过」「拒绝」。通过后申请人直接能进（项目设了二级密码的仍要输一次），被拒显示「创建者没有通过你的申请」。被踢（禁入）的账号不能申请，要先由创建者在「已禁入的账号」里解除（2026-10-08 用户新增，细则 2026-10-22 用户定）。
- 进了云端项目之后那条带「复制项目链接」的提示只在头一回进来时出：新建、凭链接加入、搬到云端（2026-10-26 用户定，issue #15）。从自己的项目列表点进已经加入过的项目不再提示；提示 8 秒后自己消失，同一时刻最多一条。氛围式的顶栏常驻一颗「复制项目链接」，任何时候都能把当前项目的链接发出去。
- 云端新建或“搬到云端”前需登录账号，创建者、成员和禁入由云端文档服务记录。云端“任何知道链接的人都可加入”默认勾选，知道链接仍需账号；取消勾选只允许账号名单，被踢账号从任何设备均不能进入。这个勾选在项目设置「作废并重新生成项目链接」「项目二级密码」两个按钮下面，只有创建者能改。账号名单就是项目成员：取消勾选那一刻已经是成员的人都在名单里，之后的新人只能申请、由创建者通过，不提供输入账号名加人（2026-10-22 用户定）。本地自报身份和进入方式不变。
- 邀请码是可作废、可限时限量的令牌，不进日志，不携带账号密码。本地项目仍等价于填对项目名和项目密码，限定进入仍需名单身份；云端只帮助定位项目，不跳过账号认证或禁入。手动表单保留。
- 账号云端项目设置里的旧按钮（2026-10-14 用户定）：
  - 「作废并重新生成邀请码」做成「作废并重新生成项目链接」：旧链接失效，已经进来的成员不受影响，新人用新链接。
  - 「改项目密码」做成「项目二级密码」：除了登录网站账号，进这个项目还要输这个密码；创建者自己不用输；已经进过的成员不再问，改了密码之后才要重新输一次。
  - 「改创建者密码」「已禁入的设备」和「这台设备上没有邀请链接」收起。
- 创建者特权：改进入设置、名单或邀请码，删项目，踢人；放云端的项目另有两项：停任何成员的云端 Agent 任务、只读查看所有成员的私有 Agent 对话、不能在里面发消息（2026-10-08 用户定，见 `../product/agent.md`）；托管方在本项目里的服务（渲染节点、云端 Agent）也只有创建者能开关；本地凭创建者用户名和密码，云端凭创建者账号。云端踢人对账号及其所有设备生效；其余操作所有成员一样。
- 项目放云端时，项目设置里另有一个勾选「云端 Agent」，缺省勾上：在线浏览器模式的成员可以在 AI 栏里用托管方的云端 Agent。项目创建者可以取消，取消后进行中的云端对话立刻停掉，别的成员收到一条气泡「创建者关闭了云端 Agent，进行中的云端对话已被停下」；重新勾上时不提示。其他成员看得到这一项，不能改。放本机的项目没有这一项。〔裁：主会话 2026-10-06，待用户合入前审〕〔用户 2026-10-07 定〕
- 自由进入下用户名可以重名，重名的人显示时自动带「(设备名)」。
- 本机 Agent 用所属用户的身份，显示为「用户名 · Agent · 第几个对话」，界面用标签区分真人和 Agent。云端 Agent 每轮按实际发起成员署名，显示为「〈用户名〉的云端 Agent」，不把共有对话的消息都归给开启者。
- 顶栏的「成员」按钮上写「成员：N 人 · Agent：M 个」：人数只算真人在线的；Agent 个数含本机 Agent 与云端 Agent；托管方的服务（渲染节点）单独一行，不计入任何一个数。成员本人不在线、只有他的云端 Agent 还连着时，他那一行照常显示并标「离线，Agent 在跑」，不计入人数、计入 Agent 个数。〔用户 2026-10-07 定〕

## 过期云端项目转本地（2026-10-08 用户定）

- 只在可信云端文档服务明确确认准确原项目已不存在或已清理时触发。文件较旧、凭证失效、超时、服务器故障或连错节点都不叫过期。
- 账号云端项目另存成文件（.proc 或 .procp）时带上「原来是哪个云端项目」的记号（2026-10-14 用户定）。重开时：
  - 没登录：提示登录，不登录就以本地副本打开、不连云端。
  - 登录的账号不是成员：提示「这个账号不是这个云端项目的成员」，以本地副本打开；项目只放账号名单时，提示里另有「发送申请」按钮（2026-10-22 用户定）。
  - 云端项目已删：走现有的「云端项目已不存在」流程，转成本地项目。
  - 本地副本里改过的内容，之后登录连回云端时当作一次普通修改合并上去；有冲突照现有的冲突处理。
- 用文件保存的那份内容建立独立本地项目，默认关闭“多用户协作”；需要协作时由用户手动打开。提示一次原云端项目已不在、现在是本地项目；各设备得到的独立副本互不再同步。
- 原云端保存之后的修改不会凭空回到旧文件；缺素材按 `materials.md` 的占位规则处理。文件里没有可用内容时报错并保留原文件，不用空项目覆盖，**需要复核各种不同细节情形**。
- 新保存更新项目状态为本地，重开继续本地设置，不再连旧云端。成功保存前保留原输入；要再放云端，登录后显式“搬到云端”。
- 独立时创建共同标记、将来从标记点合入及可视化冲突处理列为以后任务，本期不实现；不得混同下文的暂时离线重入。

## 暂时离线项目与保存（2026-10-08 用户定）

- 连接暂时失败时保留原云端关联和已知基准，允许的离线改动持久保留。未登录、旧凭证或被踢需要相应认证/拒绝处理，离线内容不授予云端写权限。
- 断网时能做的事（2026-10-22 用户定）：改项目内容的操作都允许。桌面版照常导入素材，连上后再上传；在线浏览器的导入媒体置灰，提示「当前离线」。云端 Agent 的消息断网时先排着，见 `production.md`「云端对话」。
- 保存时记录非本机内容确定快照的哈希、时间和历史序号；本机暂时禁用前台编辑，等待本机写入完成再保存。远端固定快照后仍可继续产生后续历史序号；无法取得远端确认时明确标为暂时离线，不假称已同步。
- 下次打开或重连，检查离线期间的改动并使用与撤销冲突共用的「冲突合并」窗口（2026-10-18 用户定，无冲突时也可使用该窗口以便只挑一部分修改合并）：列表的一级、二级照 `editing.md`「撤销、重做」那一条（2026-10-22 用户定：一级按被改的那样东西，二级按属性），可逐项勾选；顶端有「选中无冲突项」「取消全部勾选」两个按钮，底部有「合并」「删除选中」和「下次再说」（列表清空后变为「完成」）按钮。用户可以先勾选一部分点「合并」或「删除选中」，也可点「下次再说」关掉窗口，只要还有未处理项，导航栏顶端就常驻显示「冲突合并」按钮供随时打开继续处理；每次点「合并」提交时重新核对云端历史序号。
- 保存、重开、进程退出和提交失败都不能丢掉离线改动，也不能把暂时离线文件改成已过期的本地独立项目。

## 交付

- 导出视频：成片，以及只含卡片的透明层；可取消；可打开产物目录。在线浏览器里点导出时先选「快速导出」或「完整导出」。在线导出在跨源隔离舞台里整帧渲（所有卡连同素材一起画到画布上取像素传给导出页压视频，2026-10-14 用户定），不再因为导出页不执行同步来的卡而去等渲染节点出位图；「导出位图」仅作退路。导出完成后产物目录里只留成片与透明层〔裁：逐帧图片等中间文件不再保留，2026-09-29 PC 主会话，见 `../product/platforms.md`「导出产物」〕；历次导出在开始页「存储」里列出、可删除。
- 保存项目 `.proc`；打包保存 `.procp`（连素材一起，换机器直接打开）。
- 只读查看链接：能看不能改。

## 项目设置

名称、画幅比例与方向、帧率、分辨率、主题、创造力等级；多用户协作的开关、放在本机或云端、进入方式与创建者信息；放云端的项目另有托管方服务的开关（渲染节点、云端 Agent）；渲染节点下面另有一项「生成轨道流」，缺省关，创建者可以打开；没打开时托管方的渲染节点不为这个项目生成轨道流，播放时用成员设备生成的轨道流。打开后托管方也会生成，重卡在在线浏览器里播放更流畅，会多用云端的渲染时间（2026-10-14 用户定）。创建者不在权限分组里时这一项灰掉，提示「你的账号没有开启这一项的权限，请联系托管方。」
