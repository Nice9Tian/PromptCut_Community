# PromptCut Community

This file is deliberately short. Tools load it into every agent's context unconditionally, so it
carries only rules that every contribution to this repository must follow, whichever tool or
person writes it. The project's own working habits are not here.

## Language

- **Pull requests, issues and commit messages in the public repository
  (`Nice9Tian/PromptCut_Community`) are written in English**: titles, descriptions and comments
  alike. This applies from 2026-11-13; earlier history stays as it is.
- Commit subjects take the form `<type>: <what was done>`, with `feat`, `fix`, `refactor`, `docs`,
  `test` or `probe` as the type. Merge commits take the form `Merge <branch>: <summary>`. Every
  commit is signed off (`git commit -s`).
- The rule covers pull requests, issues and commits only. Interface text has its own rule
  (`CONTRIBUTING.en.md`, "Interface text"), and the documents under `docs/semantics/` are still
  written in Chinese: do not translate them as a side effect of other work.
- Repositories that inherit this file by merge (the commercial edition, Lite) follow the rule for
  everything they send here. What they use for commits, pull requests and issues of their own is
  theirs to decide.

## Where everything else is

`README.md` ("For coding agents"), `CONTRIBUTING.en.md` and `docs/semantics/README.md`.
